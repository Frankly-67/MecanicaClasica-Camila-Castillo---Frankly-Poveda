# Reto III.3: Asistencia gravitacional

En este reto estudiamos cómo una sonda puede aprovechar el paso cerca de Júpiter para cambiar su trayectoria alrededor del Sol y continuar hacia Saturno.

Comparamos el modelo de cónicas empalmadas con una integración numérica de la dinámica gravitacional. También analizamos las cantidades que se conservan en cada sistema de referencia y usamos el sobrevuelo de Voyager 2 como caso de comparación.

## Archivos del trabajo

- **01_Informe_Tecnico:** informe en PDF y archivo fuente en LaTeX.
- **02_Codigo_y_Datos:** programas, datos utilizados, resultados y gráficas.
- **03_Bitacora_IA:** registro del uso de herramientas de IA durante el desarrollo.
- **04_Presentacion:** diapositivas para la sustentación.
- **05_Videos:** animaciones y videos de las simulaciones.
- **06_Material_de_Apoyo:** apuntes y documentos de consulta.

Para ejecutar los programas, revisa las instrucciones que están en el README de la carpeta de código.
